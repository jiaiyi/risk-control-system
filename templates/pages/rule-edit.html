规则要素
-
支持 9 个比较符（> >= < <= == != in not_in between）+ 2 个逻辑符（and or，可嵌套）； 特征不存在判定为不命中，未知运算符判定为不命中并记警告。
取消
条件示例

单条件：

{
  "field": "login_fail_count_1h",
  "op": ">=",
  "value": 5
}

and 组合：

{
  "and": [
    {"field": "login_is_new_device", "op": "==", "value": 1},
    {"field": "login_city_count_7d", "op": ">=", "value": 3}
  ]
}

in / between：

{
  "field": "order_total_amount",
  "op": "between",
  "value": [2000, 5000]
}
保存后会发生什么
  • 规则缓存立即失效（NFR-17 热更新）
  • 下一次风控检查就用新配置
  • 新增 / 修改都会写审计流水
  • 删除是逻辑删除，历史案件的命中记录仍可追溯
